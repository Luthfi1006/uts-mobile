# uts-mobile  
**Penjualan Motor Bekas – Flutter Demo**  

A small Flutter application created for the *UTS Mobile Programming* course.  
The app displays a catalogue of used motorcycles, lets the user view details of each bike, and includes an “About Me” page with the author’s information.

---  

## ✨ Features  

| Feature | Description |
|---------|-------------|
| **Home page** | Welcome banner, category icons, and a scrollable list of motorcycles. |
| **Motorbike list** | Shows name, price, and an icon coloured per bike type. |
| **Detail page** | Tap a list item to see a larger icon, name, and price with a back‑button. |
| **About Me** | Simple profile page (name, NPM, status) reachable from the app‑bar. |
| **Responsive UI** | Uses native Flutter widgets (Scaffold, AppBar, ListView, GridView, etc.). |

## 🚀 Getting Started  

### Prerequisites  

1. **Flutter SDK** (≥ 3.12.2) – Install from https://flutter.dev/docs/get-started/install.  
2. **Android SDK / Xcode** (for running on Android/iOS).  
3. A device or emulator.

### Installation  

\\\ash
# 1. Clone the repository
git clone https://github.com/<YOUR_USERNAME>/uts-mobile.git
cd uts-mobile

# 2. Fetch dependencies
flutter pub get

# 3. Run the app
flutter run
